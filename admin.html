3. Cuidados básicos (aparecem em todas as peças)

Escreva uma vez e vale para todos os produtos. Deixe vazio para não mostrar.

Cards da página inicial

Os cards viram o banner do topo da página inicial, em largura total, e trocam sozinhos a cada 5 segundos. Use imagens do mesmo tamanho (sugestão: 1080 × 1350 px). Use “Trocar imagem” para mudar só a foto de um card.

Cupons de desconto

O cliente digita o código no carrinho. O desconto é sobre o total dos produtos e só vale se a compra chegar ao valor mínimo. Atenção: os códigos ficam dentro do arquivo do site, então quem olhar o código-fonte consegue ver. Use para promoções abertas.

Fotos na nuvem (Cloudinary)

Sem isso, as fotos novas continuam dentro do arquivo do site.

Cloudinary: crie a conta grátis, copie o Cloud name no painel e, em Settings › Upload › Upload presets, crie um preset com Signing mode “Unsigned”. Funciona só com este painel aberto como arquivo, não pelo link online.

Adicionar vários de uma vez

Em cada linha: nome primeiro e, depois, cor, linha e preço separados por vírgula, em qualquer ordem. O tipo (Brincos, Colares…) é descoberto pelo nome. Se não der (ex.: Argola), escreva o tipo na linha. A descrição é criada sozinha e você pode editar abaixo. Para várias fotos do mesmo produto, escreva “3 fotos” na linha. Para uma foto com peças numeradas, em que a cliente escolhe o número, escreva “variação 3”.
